# SRF-JRMC askSage Governance — Working-Group Routing Package

*Transmittal / table of contents. This package contains everything the working group needs to
review the askSage governance instruction in context — the standard it was built against, how it
was derived, the instruction itself, and the artifacts that stand it up. Suggested reading order
below.*

| # | Document | What it is | Read for |
|---|----------|------------|----------|
| 0 | **Cover & comment sheet** | What's decided, what the working group must resolve, comment-resolution table | Start here; capture your comments here |
| 1 | **Background brief** | Why this exists, the standard, how it was built, the decisions already made | Context before you mark up the instruction |
| 2 | **Landscape report** | What the military, corporate, federal, and regulated sectors actually do for AI governance (the standard) | Reference — the basis for the instruction's controls |
| 3 | **Draft instruction (SRF-JRMC INST 5239.[__])** | The governing policy for askSage use | The main review item — track-changes and comment |
| 4 | **Pilot authorization memo** | CO memo launching a limited, read-only pilot under the draft to validate it before promulgation | The near-term action |
| 5 | **Departmental information-governance plan (template)** | The one-page plan each code completes before its people get access | What each department fills out |
| 6 | **Training plan** | The "Responsible AI and Use" training gate — sourced + command-specific | How users qualify for access |

**How to work it:** read 0 and 1 first, skim 2 for the rationale, then review 3 (the instruction)
in detail with track-changes. 4–6 are the supporting artifacts that operationalize 3. Resolve the
"Working group to resolve" / `[CONFIRM]` markers and record comments on the cover/comment sheet.

**Fill-ins before routing** (originator): date and comments-due on the cover sheet; this package
is a draft for review, not a promulgated instruction.
